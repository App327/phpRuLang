# О библиотеке

[« Главная](Main_Page.md) | [‹ Содержание](Table_Of_Contents.md)

----

Библиотека «phpRuLang» позволяет работать с русским языком. Она написана на языке программирования PHP. Основным файлом данной библиотеки является `lib.php`.

В файле `lib.php` определён класс `phpRuLang`. Это и есть основной класс библиотеки. Все функции библиотеки находятся внутри этого класса.

На данный момент библиотека имеет не очень много функций. Со временем её функциональность будет расширяться.

## Текущая нумерация версий

На данный момент версии библиотеки формируются в формате `A.B.C[.D]`, где:

* **A** — крупнейшее обновление или готовность к релизу (на данный момент здесь _0_, потому что разработка библиотеки только началась и не все её запланированные функции готовы);
* **B** — мажорное обновление в рамках крупнейшего;
* **C** — минорное обновление в рамках мажорного;
* **D** (указывается не всегда) — патч в рамках минорного обновления.

Первой (и на данный момент текущей и единственной) версией библиотеки является `0.1.0`, вышедшая 23 августа 2026 г. Список всех версий phpRuLang можно посмотреть на GitHub в разделе «[Releases](https://www.github.com/App327/phpRuLang/releases)» («Релизы»).
