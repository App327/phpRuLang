# Функции библиотеки

[« Главная](Main_Page.md) | [‹ Содержание](Table_Of_Contents.md)

----

Ниже приведён список всех функций из библиотеки phpRuLang. Чтобы перейти к документации функции, нажмите на её название в таблице ниже.

Все эти функции находятся в классе `phpRuLang` (подробнее см. на странице «[О библиотеке](About.md)»).

| Название                                    | Описание                                                                 | Добавлена в версии | Тип возвращаемого значения                                   | Примечания                             |
|---------------------------------------------|--------------------------------------------------------------------------|--------------------|--------------------------------------------------------------|----------------------------------------|
| [`version()`](functions/version.md)         | Возвращает информацию о версии библиотеки                                | `0.1.0`            | Ассоциативный массив, строка (`string`) или `null`           | Одна из двух первых функций библиотеки |
| [`getAlphabet()`](functions/getAlphabet.md) | Возвращает алфавит русского языка в соответствии с заданными параметрами | `0.1.0`            | Массив (`array`), ассоциативный массив или строка (`string`) | Одна из двух первых функций библиотеки |
