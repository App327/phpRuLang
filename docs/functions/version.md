# Функция `version()`

[← Главная](../Main_Page.md) | [« Содержание](../Table_Of_Contents.md) | [‹ Список функций](../Functions.md)

----

## Описание

Эта функция возвращает сведения об используемой версии библиотеки «phpRuLang».

## Параметры (аргументы)

Эта функция принимает 1 параметр:

| Название    | Описание                                   | Тип данных        | Обязательный? | Значение по умолчанию | Примечания                                                           |
|-------------|--------------------------------------------|-------------------|---------------|-----------------------|----------------------------------------------------------------------|
| `$property` | Свойство, значение которого нужно получить | Строка (`string`) | Нет           | `null`                | Регистр символов имеет значение: например, `libName`, а не `LIBname` |

## Модификаторы доступа

Данная функция имеет следующие модификаторы доступа:

* Статическая (`static`)
* Публичная (`public`)

## Возвращаемое значение

Если значение параметра `$property` равно `null`, то будет возвращено всё значение переменной (свойства/поля) `$libData` из класса `phpRuLang`. В противном случае будет возвращено значение указанного в `$property` свойства. Если указанного свойства нет в `$libData`, будет возвращено `null`.

Значением переменной `$libData` является ассоциативный массив. В нём содержатся следующие свойства:

* `version` — номер версии;
* `versionRelDate` — дата выпуска версии;
* `relChannel` — канал выпуска версии (`dev`, `alpha`, `beta` или `stable`);
* `license` — лицензия, по которой распространяется phpRuLang;
* `githubLink` — ссылка на страницу phpRuLang на GitHub;
* `libName` — название библиотеки.

Любое из перечисленных выше названий свойств можно передать в качестве значения параметра `$property`.

## Типы возвращаемого значения

Функция `version()` возвращает значение одного из следующих типов:

* **Строка (`string`)** — если передано значение аргумента `$property`, и указанное свойство есть в `$libData`
* **`null`** — если передано значение аргумента `$property`, и указанного свойство нет в `$libData`
* **Ассоциативный массив** — если не передано значение `$property` (или оно равно `null`)
