# О библиотеке

Эта библиотека позволяет облегчить работу с русским языком в коде. Она написана на языке PHP. В будущем возможно расширение библиотеки и на другие языки программирования.


# Текущая функциональность

На данный момент библиотека только начинает развиваться, поэтому у неё пока что не очень много функциональности. Разумеется, запихнуть полностью весь язык в одну библиотеку невозможно, но эта библиотека старается сделать это настолько, насколько возможно.

## Список функций

* `version()` — возвращает информацию о версии библиотеки;
* `getAlphabet()` — возвращает алфавит русского языка.


# Применение

Данная библиотека может применяться в очень большом количестве проектов. Например, в текстовых редакторах, поисковых движках, платформах для создания сайтов, синтезаторах речи, переводчиках текстов и т. д.

Обратите внимание, что из-за особенностей языка (огромное количество исключений из правил) библиотека может иногда ошибаться. Обо всех таких ошибках вы можете сообщить в разделе «[https://www.github.com/App327/phpRuLang/issues](Issues)» (_Проблемы_) на GitHub.
